# 宏观经济数据看板

中美关键宏观数据实时跟踪看板，覆盖六大模块：

- 宏观指标：中国 CPI/PPI/社零/社融/PMI，美国 CPI/核心CPI/PCE/非农/联邦利率/PMI 等
- 国债收益率：中、美、日
- 汇率：美元兑离岸人民币/日元/韩元、人民币兑日元
- 大宗商品：黄金/白银/比特币/WTI/布伦特/铜/沪金/国内原油
- 股票指数：中国科技100/价值100/银行、标普500、日经225、KOSPI
- 波动率(VIX)：上证50、沪深300、中证1000、标普500

## 数据来源

- 东方财富数据中心 / 外汇 / 期货（中国、美股、日韩指数、商品）
- 新浪财经全球期货（黄金、白银、比特币、原油、铜）
- 中债登（中国国债收益率）
- VINS 纽约大学上海波动率研究所（中国三大 VIX）
- FRED 圣路易斯联储（标普500 VIX、美债收益率、美国宏观对照）
- 中国人民银行·商务部（社融）

## 更新方式

数据由本地脚本定时抓取（每天 9 点、21 点），生成后自动推送到本仓库，GitHub Pages 即时生效。

数据源多为国内接口，抓取须在本机完成（境外服务器无法访问部分源）。
